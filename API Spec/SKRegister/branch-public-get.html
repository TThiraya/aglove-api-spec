POST/SKRegister/branch/public/get

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ทุก endpoint ตอบ HTTP 200 เสมอ แม้เป็น error — ต้องอ่านสถานะจริงจากฟิลด์ Status (200/400) และ ErrorCode ใน body
  • ErrorMessage ของ error กลุ่ม validation มีส่วนต่อท้าย (Parameter 'ชื่อฟิลด์') ติดมาด้วยเสมอ เช่น "IDCard cannot be empty. (Parameter 'IDCard')" — ห้ามเอาไปแสดงผลให้ผู้ใช้ตรง ๆ ให้ map จาก ErrorCode เอง
  • ไม่ต้องใช้ token (anonymous) — ใช้กับหน้า public /srikrung-branch/{BranchCode} (CR-7)
  • ⚠ พบข้อมูลไม่ตรงสเปก: ผลทดสอบจริงคืนค่า OwnerID, OwnerIDCard, OwnerFullName, OwnerEmail, OwnerLineID ออกมาด้วย ทั้งที่ CR-7 ระบุให้ปกปิด — ยังไม่ควรใช้ response นี้ตรง ๆ บนหน้า public จนกว่าจะแก้
  • AgentCode ไม่ใช่ field ที่ส่งได้ — ส่วน /{AgentCode} ในลิงก์คือคนที่แชร์ลิงก์ ไม่ใช่เจ้าของสาขา
  • EA16405 "Branch does not exist." ใช้ตอบรวมทุกกรณี (ไม่มีสาขา / PENDING / REJECTED / IsActive=false) โดยตั้งใจ — ห้ามเอาไปแยกสถานะแสดงผล
  • ไม่คืน AddressText และไม่คืนชื่อจังหวัด/อำเภอ/ตำบล — หน้าเว็บต้องประกอบที่อยู่เองจากฟิลด์ Address* และ resolve ชื่อจาก /Master/* เอง
