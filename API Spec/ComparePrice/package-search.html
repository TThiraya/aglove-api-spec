POST/ComparePrice/package/search

ข้อควรรู้

  • endpoint นี้ค้นหาแบบ bundle พ.ร.บ.(CMI)+VMI พร้อมกันในคำขอเดียว (PackageResultCMI มีข้อมูลจริง ไม่ null เหมือน /ComparePrice/package/ext/search ที่เป็น VMI-only)
  • CompanyCode ปล่อยว่างได้ (ค้นทุกบริษัทพร้อมกัน) — ต่างจาก /ComparePrice/package/ext/search ที่ CompanyCode ว่างไม่ได้ (error B261805)
  • ต้องส่ง EffectiveDate และ ExpireDate (endpoint /ext/search ไม่มี field นี้) รูปแบบต้องเป็น yyyy-MM-dd หรือ yyyy/MM/dd เท่านั้น — ส่ง ISO datetime เต็มจะได้ error B260204
  • ⚠️ พบว่า Pagination.TotalRecord ไม่ตรงกับจำนวนจริงใน Data[] แม้ Paging.Length เหลือที่พอ — ดู RFC-20260806 (iom): https://github.com/724-Market/AGNEW/blob/docapi/docs/rfc/iom/RFC-20260806/iom-rfc-20260806.md
  • ⚠️ พบ field CarWeight และ CarWeigth (สะกดผิด) อยู่คู่กันใน PackageResultCMI.PackageResult ยังไม่ยืนยันว่าอันไหนคือค่าที่ควรใช้จริง
