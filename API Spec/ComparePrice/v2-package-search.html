ข้อควรรู้

  • ค้นหาแพ็กเกจภาคสมัครใจ (VMI) พร้อม พ.ร.บ. ควบ (CMI) เวอร์ชัน v2 — ใช้แทน POST /ComparePrice/package/search บนหน้า /agent/order/voluntary/packages
  • Request/Response ใช้โครงสร้างเดียวกับ /ComparePrice/package/search — เปลี่ยนแค่ path
  • CarTypeID ต้องเป็นรหัสตัวเลข เช่น "110" (ไม่ใช่ "CAR"), ID รถ (CarBrandID/CarModelID) เป็นรหัส int ของ ComparePrice ไม่ใช่ GUID
  • ตัวอย่าง Response ย่อเหลือรายการแรกจากทั้งหมด 4 รายการ (ผลทดสอบ dev 25/09/2026 — AXA)
  • PackageResultCMI = แพ็กเกจ พ.ร.บ. ที่ซื้อควบได้, PackageResultVMI = แพ็กเกจภาคสมัครใจ
