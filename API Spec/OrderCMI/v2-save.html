POST/OrderCMI/v2/save

ข้อควรรู้

  • ใช้บันทึก/แก้ไขข้อมูลคำสั่งซื้อ พ.ร.บ. (CMI) ก่อนชำระเงิน — หน้าที่ใช้ในระบบ: ag.724insure.net/agent/order/compulsory/information
  • ⚠️ OrderNo ต้องเป็นเลขที่คำสั่งซื้อ พ.ร.บ. (CMI) ของตัวเอง (prefix เช่น AMC) — ห้ามส่ง GroupOrderNo (เลขที่คำสั่งซื้อรวม, prefix AMG) มาแทน มิฉะนั้นจะได้ ErrorCode 11032404 "Order does not exist." (พบจากบั๊กจริงฝั่ง FE)
  • ไม่มี field "CMIOrderNo" ใน request นี้ — ต่างจาก endpoint คู่กัน POST /OrderVMI/v1/save ที่มีทั้ง OrderNo (ของตัวเอง) และ CMIOrderNo (เลขคู่ผูก) เพราะฝั่งนี้ OrderNo คือ CMI OrderNo อยู่แล้วในตัว
  • Token ส่งใน Authorization: Bearer header ตามปกติ ไม่ใช่ field ในก้อน JSON body
  • ยืนยันแล้ว 1 negative case: ส่ง OrderNo เป็น GroupOrderNo แทน CMI OrderNo ของตัวเอง → ErrorCode 11032404 — ยังไม่ได้ทดสอบ negative case อื่น (เช่น VMIOrderNo ไม่ตรง/ไม่มีอยู่จริง)
