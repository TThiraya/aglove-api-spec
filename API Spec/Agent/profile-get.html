ข้อควรรู้

  • ดึงข้อมูลโปรไฟล์ของ Agent ปัจจุบัน (ตาม Token) — Data เป็น Array ปกติมี 1 รายการ FE อ่านที่ Data[0]
  • ไม่มี Request Body จริง (นอกจาก Token/URL ของ proxy layer) — ยืนยันตัวตนด้วย Bearer Token เท่านั้น
  • IsBranch = สิทธิ์เข้าใช้ฟีเจอร์สาขาศรีกรุง: true เปิดใช้ได้ / false บล็อกทั้งฟีเจอร์ (อ้างอิง AGNEW#143)
  • ฟิลด์ auto-fill ฟอร์มสมัครสาขาและล็อกไม่ให้แก้: AgentType, AgentID, IDCard, FirstName, LastName, Tel2 (AGNEW#143)
