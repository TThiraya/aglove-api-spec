ข้อควรรู้

  • ใช้ยกเลิกงานภายในวันกับบริษัทประกัน (IIC) โดยอ้างอิงจาก OrderNo ของ Agent Love — ระบบจะไป map เป็นเลขกรมธรรม์แล้วยิงยกเลิกไปที่บริษัทประกันให้เอง
  • ⚠️ ยกเลิกสำเร็จที่ API นี้ = ยกเลิกเฉพาะฝั่งบริษัทประกันเท่านั้น ยังไม่ถือว่าปิดงานในระบบ Agent Love — ยังต้องทำตาม flow ยกเลิกงานภายในวันของระบบต่อ คือหลังยกเลิกต้องแจ้งงานใหม่ ถึงจะถือว่าการยกเลิกสำเร็จ
  • ⛔ ยกเลิกแล้วออกกรมธรรม์เดิมกลับไม่ได้ (ยืนยัน 03/09/2026) — เป็น one-way door ห้ามเรียกถ้ายังไม่มั่นใจว่างานใหม่จะออกได้
  • ประโยชน์หลัก: เดิมยกเลิกงานภายในวันจะยกเลิกแค่ฝั่ง Agent Love ทำให้แจ้งงานซ้ำกับบริษัทประกันเดิมไม่ได้ — หลังเรียก API นี้แล้วสามารถแจ้งงานซ้ำกับบริษัท IIC เดิมได้ทันที (ไม่ต้องรอ sync)
  • การตรวจผลสำเร็จต้องเช็ค 2 ชั้น: Status = 200 และ Data.Status = "S"
  • 🔴 กรณีไม่สำเร็จ Data เป็น null (ยืนยันจากการทดสอบ 03/09/2026) — ต้องอ่านข้อความจาก ErrorMessage เท่านั้น ห้ามอ้าง Data.Msg เพราะจะ throw · Data.Msg มีเฉพาะตอน API คุยกับบริษัทประกันได้สำเร็จแล้วเท่านั้น
  • 🕘 เงื่อนไขเวลา: API อนุญาตให้ยกเลิกได้ถึง 23:59:59 ของวันที่ชำระเงิน (payment date ไม่ใช่วันที่แจ้งงาน) เกินแล้วได้ Status 400 + ErrorCode 6B07607 — หมายเหตุ: UI ฝั่ง Agent เข้มกว่านี้ คือซ่อนปุ่มยกเลิกหลัง 21.00 น.
  • ตัวอย่างสำเร็จในเอกสารนี้เป็น request/response จริงจาก Dev (OrderNo = DEV_AMC2608000032, ทดสอบ 01/09/2026)
