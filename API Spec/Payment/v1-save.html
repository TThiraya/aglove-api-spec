ข้อควรรู้

  • บันทึกวิธีชำระเงินที่เลือกไว้เท่านั้น — ยังไม่ตัดยอดจริง ต้องเรียก POST /Payment/v1/confirm ต่อถึงจะตัดยอด/ปิดงานจริง
  • ⚠️ CMIDiscountValue/VMIDiscountValue ต้อง round เป็นทศนิยม 2 ตำแหน่งก่อนส่งเสมอ ไม่เช่นนั้นจะหลุดเป็นทศนิยมยาวผิดปกติ
  • ค่า CMIDiscountValue/VMIDiscountValue ต้องตรงกับ field TotalDiscount ของ PaymentType+DiscountType คู่ที่เลือกจาก POST /Payment/v1/calculate ก่อนหน้านี้เป๊ะๆ (ไม่ใช่ Max)
  • Response สร้าง PaymentTransaction แยก 1 รายการต่อ order (CMI 1 + VMI 1 ถ้ามีทั้งคู่) ผูกกันด้วย PaymentID เดียวกัน
