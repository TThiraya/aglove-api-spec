POST/Payment/v1/calculate

ข้อควรรู้

  • Endpoint กลาง (generic) ใช้ร่วมกันได้ทั้ง /OrderCMI/v2/create และ /OrderVMI/v1/create เพราะทำงานกับ CMIOrderNo/VMIOrderNo อย่างเดียว ไม่สนใจว่า order สร้างมาจาก endpoint ไหน
  • แต่ละฝั่ง (CMIPayment/VMIPayment) มี Total (ยอดเต็มก่อนหักส่วนลด) และแยกตาม PaymentType 3 แบบ: DebitCredit (มีค่าธรรมเนียมแบบ Percent), BillPayment/Pledge (ไม่มีค่าธรรมเนียม) — แต่ละ PaymentType มี DiscountType ย่อย 3-4 แบบ (ZeroCommission/SomeCommission/FullCommission/Paper เฉพาะใน Pledge)
  • ⚠️ TotalDiscount คือ field ที่ต้องส่งต่อเป็น CMIDiscountValue/VMIDiscountValue ใน POST /Payment/v1/save — ไม่ใช่ Max
  • Max คือยอดสุทธิที่ลูกค้าต้องจ่ายหลังหักส่วนลดนี้แล้ว (ยิ่งส่วนลดมาก Max ยิ่งน้อย) มีไว้แสดงผลอย่างเดียว ไม่ใช่ field ที่ส่งต่อ
  • FullCommission (ทุก PaymentType): TotalDiscount = Total เต็มจำนวน, Max = 0 — เท่ากับไม่ลดราคาเลย ลูกค้าจ่ายเต็ม
