POST/OrderVMI/v1/summary/get

ข้อควรรู้

  • อ่านคำสั่งซื้อภาคสมัครใจ (VMI) พร้อม พ.ร.บ. (CMI) ที่ผูกกันเป็นฟอร์มแก้ไขในครั้งเดียว — รับเฉพาะ VMI OrderNo ระบบ resolve CMI OrderNo เองจาก RelationOrderNo
  • ⚠️ Branch permission ต่างจาก summary/get: เช็ค CreateUser ตรงๆ เฉพาะ JobType=NEW เท่านั้น; JobType อื่นใช้กฎ IsAllowRenew ซึ่งถ้าไม่ผ่านจะ throw แล้วตกไปเป็น D9041999 (UNKNOWN) ไม่ใช่ AUTHORIZE
  • ⚠️ Cache check เกิดก่อน validate OrderNo (ต่างจาก endpoint อื่นในชุดนี้) แต่เพราะเป็น dead cache (เขียนแล้วอ่านคืนไม่ได้) จึงไม่มีผลจริงในทางปฏิบัติ
  • ไม่มีการเช็คสิทธิ์ Branch/ownership กับ พ.ร.บ. ที่ผูกมา — แค่เข้าถึง VMI ได้ก็อ่าน CMI ได้เลย
  • Payment เป็น record เดียวที่โหลดจากฝั่ง VMI เท่านั้น (จาก PaymentID ของ VMI order) — กลุ่ม CMI ไม่มี VMIRequest และ OrderEx ไม่มี PackageID/PackageCode
