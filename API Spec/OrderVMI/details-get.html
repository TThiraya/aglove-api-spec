ข้อควรรู้

  • อ่านหน้ายืนยัน/review คำสั่งซื้อภาคสมัครใจ (VMI) เดี่ยว — ราคา re-price ใหม่จาก ComparePrice, ยอดชำระ, และคำเตือนวงเงินเครดิต (PLEDGE)
  • ต้องมี Payment และ PaymentTransaction ของออเดอร์นี้อยู่จริงเท่านั้น (ต่างจาก summary/get ที่ tolerate ได้) ไม่งั้น error D905806
  • ErrorCode D905806 รวบความล้มเหลวหลายแบบไว้ code เดียว (payment/assured/car/insure/delivery/…) ต้องแยกจาก ErrorMessage — และ error นี้จะไม่เขียน log
  • Options.CreditError ปรากฏตอนสำเร็จ (success) เฉพาะ PaymentType = PLEDGE เท่านั้น — ถ้า credit balance ดึงไม่ได้ ระบบจะ swallow แล้วขึ้นเป็นเตือน balance 0 แทน error
  • PackageDetails จะเป็น array ว่างถ้า OrderType ไม่ใช่ VOLUNTARY
  • ⚠️ AssuredDetails/CarDetails/InsureDetails/DeliveryPolicyDetails ในตัวอย่างนี้แสดงเป็น Object ว่าง เพราะเอกสารต้นทางไม่ได้ระบุ field ย่อยไว้ (มาจาก DB view ตรงๆ ไม่ใช่ DTO ที่กำหนด field ชัดเจน) — ไม่ใช่ว่า response จริงจะว่างเปล่า
