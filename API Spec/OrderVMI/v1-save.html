ข้อควรรู้

  • ⚠️ ไม่ส่ง Package มา = ลบ พ.ร.บ. ที่ผูกอยู่แบบถาวร (physical delete) ทันที ไม่มี flag ยืนยันซ้ำ — ต้องระวังเป็นพิเศษถ้าไม่ได้ตั้งใจจะลบ
  • CMIOrderNo จะถูกอ่านเฉพาะตอนส่ง Package มาด้วยเท่านั้น — ส่ง CMIOrderNo มาเดี่ยวๆ โดยไม่มี Package จะไม่ update แต่กลายเป็นลบออเดอร์นั้นทิ้งแทน
  • ⚠️ ที่อยู่ (Customer.DefaultAddress) ต้องส่งมาทั้ง object ไม่ใช่ส่งแค่ AddressID — ยืนยันจากการทดสอบจริง 20/08/2026: ส่งแค่ AddressID เดี่ยว ๆ (ตามตัวอย่างของสเปกฉบับก่อนหน้า) ได้ Status 400, ErrorCode D90318081 "Default Address does not exist." แม้ AddressID นั้นจะเป็นค่าที่ได้มาจาก /OrderVMI/v1/summary/get ของ order เดียวกันก็ตาม — พอส่งที่อยู่ครบทั้ง object (ตามตัวอย่าง Request ด้านล่าง) จึงผ่าน 200
  • ตัวอย่าง Request/Response ในเอกสารฉบับนี้เป็นข้อมูลจริงที่ยิงผ่านสำเร็จทั้งหมด (order DEV_AMV2608000012 ↔ DEV_AMC2608000018) ใช้อ้างอิง copy ได้ตรง ๆ
  • ErrorCode D9031404 ใช้ร่วมกัน 3 ความหมาย (order not found / จ่ายเงินสำเร็จแล้ว / กำลังอยู่ในขั้นตอนจ่ายเงิน) ต้องแยกความหมายจาก ErrorMessage
  • ลำดับ commit คือ พ.ร.บ. ก่อน แล้วค่อย VMI เหมือน v1/create และไม่ transactional ข้ามกัน
  • AUTHORIZE message ของ endpoint นี้สะกดว่า "Access Denied." (มี d) ต่างจาก endpoint อ่านอื่นในชุดนี้ที่สะกดผิดเป็น "Access Denie."
  • ขั้นตอนถัดไปหลัง save สำเร็จคือ POST /Payment/v1/calculate → /Payment/v1/save → /Payment/v1/confirm
