ข้อควรรู้

  • ⚠️ ไม่ส่ง Package มา = ลบ พ.ร.บ. ที่ผูกอยู่แบบถาวร (physical delete) ทันที ไม่มี flag ยืนยันซ้ำ — ต้องระวังเป็นพิเศษถ้าไม่ได้ตั้งใจจะลบ
  • CMIOrderNo จะถูกอ่านเฉพาะตอนส่ง Package มาด้วยเท่านั้น — ส่ง CMIOrderNo มาเดี่ยวๆ โดยไม่มี Package จะไม่ update แต่กลายเป็นลบออเดอร์นั้นทิ้งแทน
  • ที่อยู่ (Customer.*.AddressID) ไม่ validate เนื้อหาแล้ว ตรวจแค่ AddressID ว่ามีค่า — ต้อง save ที่อยู่ให้เสร็จก่อนแล้วค่อยส่ง AddressID มาที่นี่
  • ErrorCode D9031404 ใช้ร่วมกัน 3 ความหมาย (order not found / จ่ายเงินสำเร็จแล้ว / กำลังอยู่ในขั้นตอนจ่ายเงิน) ต้องแยกความหมายจาก ErrorMessage
  • ลำดับ commit คือ พ.ร.บ. ก่อน แล้วค่อย VMI เหมือน v1/create และไม่ transactional ข้ามกัน
  • AUTHORIZE message ของ endpoint นี้สะกดว่า "Access Denied." (มี d) ต่างจาก endpoint อ่านอื่นในชุดนี้ที่สะกดผิดเป็น "Access Denie."
