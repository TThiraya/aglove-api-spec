POST/SKRegisterBackEnd/branch/register/approve

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ทุก endpoint ตอบ HTTP 200 เสมอ แม้เป็น error — ต้องอ่านสถานะจริงจากฟิลด์ Status (200/400) และ ErrorCode ใน body
  • ErrorMessage ของ error กลุ่ม validation มีส่วนต่อท้าย (Parameter 'ชื่อฟิลด์') ติดมาด้วยเสมอ เช่น "IDCard cannot be empty. (Parameter 'IDCard')" — ห้ามเอาไปแสดงผลให้ผู้ใช้ตรง ๆ ให้ map จาก ErrorCode เอง
  • ต้องใช้ Bearer token — ไม่มีการเช็ค Admin (CR-4)
  • IsApprove=true = อนุมัติและออกเลข BRxxxx / IsApprove=false = ปฏิเสธ (ต้องมี RejectReason ไม่งั้น CC13103)
  • อนุมัติซ้ำได้แบบ idempotent — ถ้ามี BranchCode อยู่แล้วจะคืนเลขเดิม ไม่ออกเลขใหม่และไม่ประทับเวลาใหม่ (ทดสอบยืนยันแล้ว)
  • สาขาที่ approve ไปแล้ว reject ไม่ได้ → CC13606 "Approved branch cannot be rejected."
  • เลขรันมาจาก MAX(BranchCode)+1 ใน transaction แบบ Serializable — ไม่มี unique index บน BranchCode จึงซ้ำกันได้ ระบบไม่ปฏิเสธเลขซ้ำ
  • RejectReason ถูกตรวจความยาว 0-255 แม้ตอนอนุมัติ ที่ค่านี้ไม่ถูกใช้
  • ⚠ พบปัญหา config: BranchLink บน dev ออกมาเป็น "/BR0001" ไม่มี host เพราะ app setting SKBranchLinkUrl ว่าง — ต้องตั้งค่าก่อนขึ้น UAT/Production
