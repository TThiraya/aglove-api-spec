POST/SKRegisterBackEnd/branch/report/summary

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ทุก endpoint ตอบ HTTP 200 เสมอ แม้เป็น error — ต้องอ่านสถานะจริงจากฟิลด์ Status (200/400) และ ErrorCode ใน body
  • ต้องใช้ Bearer token — ไม่มีการเช็ค Admin (CR-9)
  • ไม่มีการ validate field ใด ๆ เลย — วันที่ที่ parse ไม่ได้จะถูกเมินเงียบ ๆ (กลายเป็นไม่จำกัดช่วง) ไม่ใช่ error
  • DateTo รวมวันที่ระบุด้วย (server บวก 1 วันแล้วเทียบ <)
  • BranchCode ว่าง = ทุกสาขา และเป็นการ match แบบตรงตัว ไม่ใช่ LIKE
  • Summary ไม่ใช่ผลบวกของ Items — คำนวณแยกด้วย COUNT(DISTINCT) ห้ามเอา Items มาบวกเอง
  • Items แยกแถวต่อเรคคอร์ดสาขา (group by ID) ไม่ใช่ต่อ BranchCode — สาขาที่ BranchCode ซ้ำกันจะได้คนละแถว
  • สาขาที่ยัง PENDING (BranchCode เป็น null) ไม่ถูกนับเลย
  • ไม่เจอข้อมูล → Items: [] และ Summary เป็นศูนย์ทั้งหมด ไม่ใช่ null
