POST/SKRegisterBackEnd/branch/register/grid/list

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ต้องใช้ Bearer token และต้องเป็น Admin (CC11788 ถ้าไม่ใช่) — CR-3
  • response ไม่ใช่ envelope มาตรฐาน แต่เป็น DataTable (status/draw/recordsTotal/recordsFiltered/data ตัวพิมพ์เล็ก)
  • ไม่มีแถว → data เป็น "" (string ว่าง) ไม่ใช่ [] — client ต้องเช็ค type ก่อน map
  • draw, start, length ถูก cast แบบไม่เช็ค null — ไม่ส่งตัวใดตัวหนึ่งจะพังเป็น CC11999
  • length ถูกจำกัดที่ 100 และ data ถูก .Take(100) ซ้ำอีกชั้น
  • recordsTotal กับ recordsFiltered เป็นค่าเดียวกันเสมอ (ยอดหลังกรอง) — ยอดก่อนกรองไม่เคยถูกคำนวณ
  • วันเวลาในกริดฟอร์แมต yyyy-MM-ddTHH:mm:ssZ และ null กลายเป็น "" — ต่างจาก branch/register/get ที่เป็น .NET raw
