POST/SKRegisterBackEnd/branch/register/get

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ทุก endpoint ตอบ HTTP 200 เสมอ แม้เป็น error — ต้องอ่านสถานะจริงจากฟิลด์ Status (200/400) และ ErrorCode ใน body
  • ErrorMessage ของ error กลุ่ม validation มีส่วนต่อท้าย (Parameter 'ชื่อฟิลด์') ติดมาด้วยเสมอ เช่น "IDCard cannot be empty. (Parameter 'IDCard')" — ห้ามเอาไปแสดงผลให้ผู้ใช้ตรง ๆ ให้ map จาก ErrorCode เอง
  • ต้องใช้ Bearer token — แต่ไม่มีการเช็ค Admin ต่างจาก branch/register/grid/list (CR-3)
  • field ที่ส่งคือ ID ไม่ใช่ BranchRegisterID ตามที่ draft ของ issue #26 เคยเสนอ
  • เป็น มุมมองฝั่ง admin จึงคืน PII ของเจ้าของสาขา (OwnerIDCard ฯลฯ) ต่างจาก branch/public/get
  • ⚠ พบ bug จริง: AddressText คำนำหน้าซ้ำ — ได้ "...ตำบลตำบลช้างคลาน อำเภออำเภอเมือง..." เพราะ BuildAddressText เติม "ตำบล"/"อำเภอ" ทับชื่อจาก master ที่มีคำนำหน้าอยู่แล้ว
  • BranchLink เป็น null ตราบใดที่ยังไม่ approve (ยังไม่มี BranchCode)
  • วันเวลาเป็น .NET raw (ไม่มี Z) ต่างจากกริด
