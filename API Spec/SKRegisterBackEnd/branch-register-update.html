POST/SKRegisterBackEnd/branch/register/update

ข้อควรรู้

  • Base URL dev: https://api-cnt-aglove.724insure.net — ทดสอบจริงเมื่อ 03/09/2026
  • ทุก endpoint ตอบ HTTP 200 เสมอ แม้เป็น error — ต้องอ่านสถานะจริงจากฟิลด์ Status (200/400) และ ErrorCode ใน body
  • ErrorMessage ของ error กลุ่ม validation มีส่วนต่อท้าย (Parameter 'ชื่อฟิลด์') ติดมาด้วยเสมอ เช่น "IDCard cannot be empty. (Parameter 'IDCard')" — ห้ามเอาไปแสดงผลให้ผู้ใช้ตรง ๆ ให้ map จาก ErrorCode เอง
  • ต้องใช้ Bearer token — ไม่มีการเช็ค Admin (CR-6)
  • เป็น full-record update ไม่ใช่ patch — ต้องส่งค่าปัจจุบันของทุกฟิลด์ที่ต้องการคงไว้
  • ไม่ส่ง BranchCode = ล้างค่าทิ้ง ทำให้ลิงก์ที่แชร์ไปแล้วใช้ไม่ได้ทันที
  • OwnerAgentCode แก้ไม่ได้ (ไม่ใช่ field ที่รับ)
  • คอลัมน์ที่ request ไม่ได้ส่งมา (Status, IsActive, OwnerID, OwnerIDCard, ApproveUser, ApproveDate, CreateUser, CreateDate ฯลฯ) จะ round-trip กลับไปเหมือนเดิม
  • ไม่เช็ค BranchCode ซ้ำ และไม่ cascade — order เดิมที่ผูกไว้ยังผูกอยู่ผ่าน SKBranchRegisterID แต่ลิงก์ BRxxxx เดิมจะ resolve ไม่เจอ
  • เรคคอร์ดถูกอ่าน 2 รอบ (view แล้ว table) ใช้ error code คนละตัวสำหรับเงื่อนไขเดียวกัน — CC14405 คือตัวที่จะเจอปกติ ส่วน CC14407 เกิดเฉพาะตอน race
