ข้อควรรู้

  • ค้นหาแพ็กเกจ พ.ร.บ. (CMI) เวอร์ชัน v2 — ใช้แทน POST /Policy/package/list บนหน้า /agent/order/compulsory/packages
  • Request/Response ใช้โครงสร้างเดียวกับ /Policy/package/list — เปลี่ยนแค่ path
  • ต้องส่ง LicenseProvinceID (GUID จังหวัดทะเบียนรถที่ agent เลือก) ทุกครั้ง ห้ามส่งค่าว่างหรือ null — ระบบใช้ค่านี้คำนวณค่าคอมมิชชั่นตามที่กำหนดใหม่
  • ผลทดสอบ dev 25/09/2026: ถ้าส่ง LicenseProvinceID เป็นค่าว่าง ระบบจะไม่กรองบริษัทตามจังหวัดที่เปิดขาย (ได้ 13 บริษัท แทน 11 — มี ANC และ IIC ที่ไม่เปิดขายใน กทม. ติดมาด้วย)
  • ตัวอย่าง Response ย่อเหลือบริษัทแรกจากทั้งหมด 11 บริษัท (ผลทดสอบ dev 25/09/2026 — Honda Brio 2021 / ทะเบียน กทม.)
  • ค่าคอมมิชชั่น/ส่วนลดที่แสดงให้ agent ใช้ ComissionAgent และ AgentComDiscount ใน Data[].PackageResult[]
